Deep Dive Concepts & Mechanics

$lookup (Left Outer Join)
The Plain-English Breakdown: Performs a join with another collection in the same database to filter in documents from the 'joined' collection.
Real-World Use Case: Fetching user details alongside their recent orders (joining 'orders' with 'users').
⚠️ The "Gotcha": The result is ALWAYS an array (even if there's only one match). You usually need an $unwind stage right after a $lookup.
💡 Memorization Hook: $lookup = SQL JOIN.

Examiner: What data type does the 'as' field in a $lookup produce?
It produces an array containing all matching documents from the foreign collection.
