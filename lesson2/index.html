Deep Dive Concepts

Comparison Operators ($gt, $lt, $in, $ne)

The Plain-English Breakdown: These operators allow filtering documents based on specific value comparisons rather than exact matches. $in matches any value in an array.

Real-World Use Case: Finding users over a certain age ($gte: 18) or products within a price range.

The "Gotcha" (Common Pitfalls): $in takes an array of values. Forgetting the brackets (e.g., $in: 'nitan') will result in an error or unexpected behavior.

Memorization Hook: Prefix with $ for operators: $gt (greater than), $lt (less than), $ne (not equal).

Examiner Q&A Simulator

Click a question to reveal the answer.

Examiner: How would you find students whose age is exactly 25 or 30?
Use the $in operator: { age: { $in: [25, 30] } }
Examiner: Can you use multiple comparison operators on the same field?
Yes, for example { age: { $gte: 18, $lte: 30 } } finds ages between 18 and 30 inclusive.
