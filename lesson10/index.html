Deep Dive Concepts & Mechanics

$unwind
The Plain-English Breakdown: Deconstructs an array field, outputting a new document for each element of the array. The other fields are duplicated.
Real-World Use Case: Analyzing tags on blog posts. To count tags, you must first unwind the tags array.
⚠️ The "Gotcha": If a document has an empty array or null for that field, $unwind removes the document entirely unless you use preserveNullAndEmptyArrays: true.
💡 Memorization Hook: $unwind explodes an array into multiple documents.
$group
The Plain-English Breakdown: Groups documents by a specified _id expression and applies accumulator expressions ($sum, $max).
Real-World Use Case: Finding the total sales per region, or the maximum age per gender.
⚠️ The "Gotcha": The _id field in $group is mandatory. It determines what you are grouping BY. If you want to group everything into one result, use _id: null.
💡 Memorization Hook: _id is the 'GROUP BY' key.

Examiner: How do you group all documents in a collection together to find the global average?
You set the _id field in the $group stage to null: { $group: { _id: null, avg: { $avg: '$price' } } }.
