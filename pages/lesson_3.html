Deep Dive Concepts

Logical $or and $exists

The Plain-English Breakdown: $or evaluates an array of conditions and returns documents that match at least one. $exists checks if a field is present, regardless of its value.

Real-World Use Case: Finding users who either live in 'kathmandu' OR are married. Finding documents where an optional field was actually saved.

The "Gotcha" (Common Pitfalls): $or must be an array of objects. Also, $exists: false will return documents where the field doesn't exist, which is different from a field existing with a null value.

Memorization Hook: $or is an array of conditions. $exists is a boolean.

Examiner: What is the difference between $exists: true and checking for null?
A field can exist and have a value of null. $exists: true matches it, but checking {field: null} matches both null values and non-existent fields (in some driver contexts).
Examiner: How do you structure an $or query?
It takes an array of query objects: { $or: [ {condition1}, {condition2} ] }
