# MongoDB Learning Site

This repository has been transformed into a simple, static educational website for self-learning MongoDB concepts. It uses plain HTML/CSS/JS and can be hosted directly on GitHub Pages.

## How to use

Simply open `index.html` in your browser, or start a local server, e.g., `python -m http.server 8000` and visit `http://localhost:8000`.
